# TSV Nettelkamp Handball Manager – V1.0.0-RC1 Mobile Draft

Entwurf für eine optimierte iPhone-Oberfläche auf Basis des funktionierenden RC1.

## Schwerpunkt
- kompakter mobiler Header mit Mannschaftsauswahl
- mobile Seiten-Navigation
- Touch-optimierte Buttons und Formulare
- Dashboard als 1-/2-spaltiges Kartenlayout
- mobile Trainings-/Anwesenheitsdarstellung
- Safe-Area-Unterstützung für moderne iPhones
- Desktop-Funktionalität bleibt unverändert

Dies ist eine Testversion und noch kein Release.
